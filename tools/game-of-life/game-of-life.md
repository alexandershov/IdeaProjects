## Game of life

### What is it?

A cellular automata with these rules:
* Infinite grid of cells
* Every cell is either dead or live
* if cell is live and has 2 or 3 live neighbours it survives till the next generation
* if cell is dead and has 3 live neighbours it becomes live

See [game-of-life.html](./game-of-life.html) for an implementation in Javascript.

Game of life is surprisingly rich and can simulate a Turing machine.
