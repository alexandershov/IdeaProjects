# Prolog

## What is it?
Prolog is a logical programming language.


## Install
```shell
brew install swi-prolog
```

## Usage
```shell
# this will read a file and start Prolog top-level
swipl tutorial.pl
```

In Prolog top-level you can ask questions:
```
?- grandfather(X, Y).
```

Prolog will find answers.
