# Tcl

## What is it?
Tcl is a scripting language created by John Ousterhout.

See [tutorial.tcl](./tutorial.tcl) for more details.

## Install
MacOs bundles older (8.5) version of tcl and Tk is kinda broken there, so install from homebrew: 
```shell
brew install tcl-tk
```

## Usage

wish is for Tk apps (WIndowing SHell):
```shell
wish9.0 tutorial.tcl
```

tclsh is for CLI apps.
