# Lean

## What is it?
Lean is a proof assistant & functional programming language. Kinda similar to Coq but more practical.


## Install
```shell
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh

```

## Usage

```shell
~/.elan/bin/lean --run tutorial.lean
```
It runs successfully which means theorem is proven.
